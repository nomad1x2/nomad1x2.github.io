Qwertypy - A simple "keyboard walk" string generator

Keyboard walking is a technique where characters are chosen based on their position on the keyboard. Instead of picking random letters, you just move in a direction -- like across a row or down a column. Think qwerty, asdf, zxcvbn, or 1qaz2wsx.

These patterns show up all the time in real-world passwords, especially from people who think they’re being clever or just want something easy to type. Because of that, walks are a goldmine when building wordlists for cracking.

This is a super simple script that automates this by taking a word or phrase and generating keyboard-based variations from it, following the physical layout of the keys. It’s meant to expand password lists with realistic patterns that users might actually type -- not random junk.

The layout is customizable, so you can tweak it to match different keyboards or add your own weird rules.

def get_key_index(key, keyboard):
    for row_index, row in enumerate(keyboard):
        for case in ['lower', 'upper']:
            if key in row[case]:
                col_index = row[case].index(key)
                return {
                    "row": row_index,
                    "case": case,
                    "column": col_index
                }
    return None
   
def standard_deviation(word, keyboard):
    cipher = []

    for key in word:
        key_info = get_key_index(key, keyboard)
        if not key_info:
            continue

        row = key_info['row']
        col = key_info['column']

        for i in range(row, -1, -1):
            try:
                temp = keyboard[i]['lower'][col]
                if temp is not None:
                    cipher.append(temp)
            except IndexError:
                continue

        for i in range(0, row + 1):
            try:
                temp = keyboard[i]['upper'][col]
                if temp is not None:
                    cipher.append(temp)
            except IndexError:
                continue

    return ''.join(cipher)

while True:
    user_input = input("Input: ").lower()
    if user_input == 'exit':
        break
    print(f"Walk: {standard_deviation(user_input, standard_qwerty)}\n")
